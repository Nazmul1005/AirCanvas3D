# Screenshots and Images

This directory contains screenshots and images for documentation.

## Recommended Screenshots to Add

Take screenshots of your running application and save them here:

1. **main-interface.png** - The main 3D interface with toolbar and webcam preview
2. **hand-tracking.png** - Debug window showing hand landmarks
3. **drawing-demo.png** - Example of 3D strokes being drawn
4. **block-building.png** - Example of blocks being placed
5. **gesture-examples.png** - Collage of different gestures
6. **tutorial-overlay.png** - The tutorial screen
7. **color-picker.png** - Color selection interface
8. **save-load.png** - Save/Load functionality

## How to Take Screenshots

### macOS
- Full screen: `Cmd + Shift + 3`
- Selected area: `Cmd + Shift + 4`
- Window: `Cmd + Shift + 4` then `Space`

### Windows
- Full screen: `Windows + PrtScn`
- Selected area: `Windows + Shift + S`

### Linux
- Use `gnome-screenshot` or `scrot`

## Image Guidelines

- **Format**: PNG (for UI screenshots) or JPG (for photos)
- **Resolution**: At least 1280×720, preferably 1920×1080
- **Size**: Optimize to keep under 500KB per image
- **Naming**: Use lowercase with hyphens (e.g., `hand-tracking.png`)

## Optimization Tools

- [TinyPNG](https://tinypng.com/) - Compress PNG/JPG
- [Squoosh](https://squoosh.app/) - Web-based image optimizer
- ImageMagick: `convert input.png -quality 85 output.png`
